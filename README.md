## 🧩 Featured Projects

### 🛒 [Full-Stack E-commerce Application](https://github.com/MuhammadMusabYaqoob/E-commerce-Full-Stack-Web-Application)

**Vue.js | Node.js | Express.js | PostgreSQL | MongoDB | Axios | Cloudinary | Tailwind CSS**

Developed a full-stack e-commerce application with product management, user authentication, shopping cart, checkout, and order management.

- Implemented backend APIs for authentication, products, categories, and orders.
- Integrated Axios for frontend-backend communication and Cloudinary for image uploads.
- Implemented JWT authentication, HTTP-only cookies, bcrypt password hashing, and role-based authorization.
- Worked with PostgreSQL and MongoDB using Mongoose.

### 🚀 [Knowledge-Transfer-Agent](https://github.com/muhammadmusabyaqoob/Knowledge-Transfer-Agent)

**Python | FastAPI | LangChain | RAG | Gradio**

An AI-based onboarding system designed to enable smooth knowledge handover between employees.

Allows new hires to ask questions about company documents using document-based Q&A and AI-powered knowledge retrieval.

**n8n | Gemini | NewsAPI | Google Sheets | Gmail**

An automation workflow that extracts email topics, fetches related news, performs sentiment analysis, and sends daily AI-generated summaries.

### 🤖 [AI Voice Customer Support Agent](https://github.com/MuhammadMusabYaqoob/AI-Voice-Customer-Support-Agent)

**Python | Whisper | Gemini | gTTS | Gradio**
